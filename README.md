# Deepfakedetector
🎭 Deepfake Detector Web App
A web application that uses deep learning and computer vision to detect manipulated media (deepfakes). Users can upload videos or images and quickly determine if they are real or fake.
🔗 [[Live Demo]](https://t.co/GWFSBivN9B)
Access the deployed app here

🛠 Features
Detects deepfake videos and images using a trained AI model.
User-friendly web interface for quick uploads.
Instant feedback on media authenticity.
Node.js backend with Express.js API for media processing.

💻 Technologies Used
Frontend: HTML, CSS, JavaScript
Backend: Node.js, Express.js
Machine Learning: TensorFlow.js / Python ML model served via API
Other Libraries: OpenCV, Multer (for file uploads)
